# Project Rules - UyuniAdmin Frontend

This directory contains modular guidelines and coding standards for AI coding agents and developers.

## Rule Files

| File | Purpose |
|------|---------|
| [`project-rules.md`](./project-rules.md) | High-level project identity, key principles, and memory links |
| [`angular-standards.md`](./angular-standards.md) | Angular 21, standalone components, signals, OnPush, and DI conventions |
| [`primeng-standards.md`](./primeng-standards.md) | PrimeNG 21, `@primeuix/themes`, class vs styleClass, and Lucide icons |
| [`tailwind-v4.md`](./tailwind-v4.md) | Tailwind CSS v4 syntax (`!` suffix) and enterprise high-density UI guidelines |

## Priority
In case of conflicts:
1. Specific domain rules (`angular-standards.md`, `tailwind-v4.md`, `primeng-standards.md`) take precedence on their respective topics.
2. Root [`AGENTS.md`](../../AGENTS.md) represents the primary unified contract for all agents.
